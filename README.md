# Software Development Journey

**Hành trình học lập trình và phát triển phần mềm**

## About This Repository | Giới thiệu

**English**

This repository documents my journey of learning programming, Python, and software development from the fundamentals. I will build a strong foundation, practice regularly, and explore different areas of technology as I progress.

**Tiếng Việt**

Kho lưu trữ này ghi lại hành trình học lập trình, Python và phát triển phần mềm từ những kiến thức nền tảng. Tôi sẽ xây dựng nền tảng vững chắc, thực hành thường xuyên và khám phá các lĩnh vực công nghệ khác nhau trong quá trình học.

## Learning Goals | Mục tiêu học tập

- Learn programming fundamentals. — Học kiến thức lập trình căn bản.
- Learn Python step by step. — Học Python từng bước.
- Practice Git and GitHub. — Thực hành Git và GitHub.
- Build practical software projects. — Xây dựng các dự án phần mềm thực tế.
- Explore automation, data, AI, and other technologies. — Khám phá tự động hóa, dữ liệu, AI và các công nghệ khác.

- [ ] Python fundamentals — Python căn bản

- Learn from mistakes and improve continuously. — Học từ sai lầm và liên tục cải thiện.
